Data storage and deletion

This is what the live server does today. It matches the app, not a future policy.

What is stored with an account

Email, a scrypt password hash when you set a password (not the password itself), your name and phone if you add them, whether Plus is active, today’s Hope message count, saved chats for each profile, check-ins, and weekly goals. Card numbers are not stored by Hopewick.

Memories, the journal, recovery plans, and the resume draft stay on this device. Signed-in check-ins and weekly goals are also saved to the account.

How long chats stay

A chat on the live server is kept until you delete that chat, you delete the account, or the chat has not been updated for 24 months. 24 months is 730 days of 24 hours, counted from the conversation’s updated time. A missing updated time is treated as expired. The check runs when that account’s chats are read or saved. There is no separate nightly job.

Free and Plus use the same retention rule. A free account can open only the latest chat. Older chats can still be stored. Not seeing them is not deletion. Hopewick Plus can open stored history that is still there.

This rule does not clear the copy in your browser, and it does not wipe a disk snapshot.

Deleting one chat

Deleting one chat removes that chat from the account save. It does not delete the rest of the account, and it does not, by itself, clear a copy that is only in this browser.

Deleting the account

Delete account, in the app, removes the live server sign-in, that account’s server chats, check-ins, and weekly goals, and signs you out. It does this straight away. It does not wait 24 months.

If Plus is current, deletion cancels that subscription straight away. If the subscription cannot be cancelled, the account is not deleted.

What can remain:

  • A copy in this browser, including chats, journal, check-ins, weekly goals, and profiles, until you clear it in Settings.
  • Stripe may keep invoices. Hopewick does not store your card number.
  • Existing Render disk snapshots can still hold older data. Deleting an account does not wipe them, and this page does not promise they disappear at once. It also does not say how long a snapshot is kept.

On 3 October 2026 the newest snapshot was restored onto the live disk. Files were not compared one by one.

If you cannot delete the account in the app

Email admin@bridge-bite-co.com from the account’s sign-in address and ask for the account to be deleted. A person handles that request. It is not automatic. The aim is to delete the same server account, server chats, check-ins, and weekly goals, and to cancel a current subscription. It still does not wipe a browser copy, Stripe invoices, or a disk snapshot.

More on how to write, and what we aim to reply, is on the complaints page.
